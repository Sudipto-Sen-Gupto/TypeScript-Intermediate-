# 🚀 TypeScript Intermediate Guide

Welcome to this **TypeScript Intermediate Level README**.  
This guide covers important concepts to help you write **scalable, reusable, and type-safe code**.

---

## 📚 Topics Covered

### 🔹 1. Type Assertion
Type Assertion allows you to manually specify the type of a value when TypeScript cannot infer it correctly. It gives more control over types but should be used carefully.

---

### 🔹 2. Interface
Interface is used to define the structure of an object. It ensures consistency and helps in maintaining clean and organized code.

---

### 🔹 3. Difference Between Type Assertion and Interface
- **Type Assertion** → Used to override or define a type manually.
- **Interface** → Used to design the structure of objects.
👉 Assertion is for control, Interface is for structure.

---

### 🔹 4. Generics
Generics allow you to create reusable components that work with multiple data types while keeping type safety intact.

---

### 🔹 5. Generics with Functions and Tuple
Generics can be applied to functions and tuples to maintain flexibility and ensure consistent types across inputs and outputs.

---

### 🔹 6. Constraint
Constraints restrict the types that a generic can accept. This improves reliability and prevents invalid data usage.

---

### 🔹 7. `keyof` Constraint
`keyof` is used to ensure that only valid keys of an object are used, making your code safer and more predictable.

---

### 🔹 8. Enum
Enum is used to define a set of named constants, making your code more readable and easier to manage.

---

### 🔹 9. `as const`
`as const` makes values immutable and more specific by converting them into literal types.

---

### 🔹 10. `keyof` and `typeof`
- **`typeof`** → Gets the type of a variable.
- **`keyof`** → Gets the keys of a type.
👉 Together, they help in dynamic type creation.

---

### 🔹 11. `key in`
Used in mapped types to iterate over object keys and create new types from existing ones.

---

### 🔹 12. Conditional Types
Conditional types allow you to define types based on conditions, making your type system more dynamic.

---

### 🔹 13. Loop on Type
TypeScript supports looping over types using mapped types, which helps in transforming types efficiently.

---

### 🔹 14. Utility Types
Utility types are built-in helpers that simplify common operations like making properties optional, required, or readonly.

---

- Build scalable applications  
- Improve type safety  
- Prepare for real-world projects
